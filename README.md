Project "Social"

Description:

Social is a project based on Next.js that uses Firebase as a backend and TailwindCSS for interface design.

Technologies Used:

. Node.js: (preferably version 18.20.7)

. Next.js

. Firebase

. TailwindCSS
-------------------------------------------------
Project Installation

1. Clone the repository

 git clone https://github.com/tuusuario/social

2. Navigate to the project directory

# cd social

3. Switch to the staging branch and install dependencies

Install the package manager Yarn. !!

# npm install -g yarn

Check available branches:

# git ls-remote --heads origin

List local branches:

# git branch

Switch to the staging branch and verify:

# git checkout staging
.
-------------------------------------------------
Install dependencies:

# yarn install

4. Attach the .env environment variable file !!!!

5. Run the local development server

# yarn dev

The project will be available at: http://localhost:3000
